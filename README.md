## 📌 Описание

Бэкенд-сервис для бронирования отелей с административной панелью управления и модулем сбора статистики. Пользователи
могут искать отели и комнаты, бронировать номера на свободные даты, а администраторы — управлять данными и выгружать
статистику в формате CSV.

## 🚀 Технологии

- Java 21
- Spring Boot 3.3.4
- Spring MVC
- Spring Data JPA + PostgreSQL
- Spring Security (Basic Auth)
- MapStruct
- MongoDB
- Kafka + ZooKeeper
- Docker + Docker Compose

## ⚙️ Функциональность

### 🏨 Работа с отелями

- CRUD-операции для отелей
- Фильтрация и пагинация
- Выставление рейтинга пользователями

### 🛏️ Работа с комнатами

- CRUD-операции для комнат
- Поиск с фильтрацией (по цене, дате, количеству гостей и т.п.)
- Проверка доступности на указанные даты

### 👤 Работа с пользователями

- Регистрация и авторизация
- CRUD-операции
- Роли: `USER`, `ADMIN`

### 📅 Бронирование

- Оформление брони пользователями
- Получение списка всех броней (только для администратора)
- Проверка на пересечения по датам

### 🔐 Безопасность

- Spring Security с Basic Auth
- Ограничение доступа к эндпоинтам в зависимости от роли

### 📊 Статистика

- Сбор данных о регистрации пользователей и бронированиях
- Хранение в MongoDB
- Выгрузка статистики в CSV (только для администратора)
- Использование Kafka для обработки событий

## 🐳 Запуск с Docker

```bash
docker-compose -f docker-compose.yaml up --build
```
